══════════════════════════════════════════════════════════════
  ФУНКЦИОНАЛ ДЛЯ ПОЛЬЗОВАТЕЛЕЙ
══════════════════════════════════════════════════════════════

🛍 КАТАЛОГ ТОВАРОВ
  • Товары разбиты по группам (категориям)
  • Внутри каждой группы список товаров с ценами
  • Карточка товара: название, цена, кнопка «Купить»
  • Оплата списывается с внутреннего баланса

🔍 ПОИСК ПО НАЗВАНИЮ
  • Кнопка «🔍 По названию» доступна как в списке групп,
    так и внутри каждой группы
  • Поиск по любому слову из введённой фразы
  • Из результатов поиска — кнопка «⬅️ Назад» в каталог

👤 ПРОФИЛЬ
  • Просмотр своего Telegram ID и имени
  • Активация промокода для пополнения баланса
  • История покупок (название товара, цена, дата)

💰 БАЛАНС
  • Просмотр текущего баланса
  • Пополнение через CryptoBot (USDT / TON)
  • Пополнение через xRocket (TON)
  • Пополнение через Telegram Stars
  • Выбор суммы пополнения (10 / 50 / 100 / 250 / 500 / 1000 ₽)

❓ FAQ
  • Ссылка на информационный канал

🆘 ПОДДЕРЖКА
  • Система тикетов — сообщение напрямую доходит до админа


══════════════════════════════════════════════════════════════
  ФУНКЦИОНАЛ АДМИН-ПАНЕЛИ (/admin)
══════════════════════════════════════════════════════════════

➕ ДОБАВИТЬ ТОВАР
  • Если групп нет — сначала предлагает создать группу
  • Если группы есть — выбрать существующую или создать новую
  • Шаги: группа → название → цена → тип содержимого
  • Типы содержимого: текст / ссылка / файл / текст+фото

📂 ГРУППЫ ТОВАРОВ
  • Просмотр всех групп
  • Создание новой группы
  • Переименование группы
  • Удаление группы (товары в ней становятся без группы)

📦 СПИСОК ТОВАРОВ
  • Все товары с ценами
  • Нажатие на товар — редактирование или удаление

🎟 СОЗДАТЬ ПРОМОКОД
  • Шаги: код → сумма пополнения → количество использований
  • Каждый пользователь может использовать промокод только 1 раз

👥 ВЫГРУЗИТЬ ЮЗЕРОВ
  • Скачать .txt файл со списком всех пользователей
  • В файле: имя, @username, ID, дата регистрации

📊 СТАТИСТИКА
  • Пользователи, активность, продажи, выручка

🔧 ТЕХ. РЕЖИМ
  • Включить / выключить — блокирует доступ для не-админов

  СТРУКТУРА ФАЙЛОВ
══════════════════════════════════════════════════════════════

bot.py          — точка входа, регистрация роутеров
config.py       — токен бота, пароль, ID админов, ссылки
database.py     — вся работа с БД (SQLite)
keyboards.py    — все клавиатуры
utils.py        — вспомогательные функции
shop.db         — база данных (создаётся автоматически)
requirements.txt — зависимости
start.bat       — запуск бота

handlers/
  common.py     — /start, кнопка «Назад в меню»
  products.py   — каталог, группы, карточка товара, поиск
  admin.py      — вся админ-панель
  balance.py    — пополнение баланса
  profile.py    — профиль и история покупок
  faq.py        — FAQ
  support.py    — поддержка
