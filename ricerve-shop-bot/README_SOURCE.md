# Ricerve Shop Bot — исходники

В архиве находятся исходники изменённого Telegram-магазина.

## Запуск

1. Установите зависимости из `requirements.txt` или используйте зависимости проекта.
2. Добавьте секрет `BOT_TOKEN` в переменные окружения.
3. Запустите:

```bash
python bot.py
```

Токен и база данных намеренно не включены в архив.

## Основные изменения

- Нижнее reply-меню без отдельного inline-меню главного экрана.
- Каталог, профиль, FAQ, поддержка и админ-панель.
- Управление ссылкой канала из админки.
- Выдача админских прав зарегистрированному пользователю по `@username`.
- Постоянное хранение настроек и дополнительных администраторов в SQLite.
